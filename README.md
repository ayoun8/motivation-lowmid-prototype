# Motivation Low-to-Mid Fidelity Prototype

A clickable HTML prototype for a college-student Quizlet redesign: a study pet, labeled concept-review feedback, peer guidance, independent practice, and a completion reward.

Open index.html in a browser. Only one Biology activity is implemented; peer responses are simulated and progress lasts while the page is open.

Created with AI assistance based on the student's design direction and feedback.
